# 小憩小游戏

侧边栏底部的手柄图标或 `Ctrl+Alt+G` 打开小憩。图标与侧边栏其他入口保持 18×18、按钮 34×34，侧边栏隐藏时入口一起隐藏，快捷键仍可使用。Markdown 编辑、源码模式及纯文本编辑共用同一个独立浮层，不往正文插入任何游戏数据。

## 操作

也可以在正文独占一行输入 `::game 2048`，直接渲染可玩的游戏卡片。全部游戏语法和保存规则见 [GAME-MARKDOWN.md](GAME-MARKDOWN.md)。

- `Esc` 或再次按 `Ctrl+Alt+G` 收起并恢复先前编辑焦点和浏览器选区。
- 点击浮层外、窗口失焦或页面进入后台时立即收起；重新打开由用户主动触发。
- 原有三款游戏的局面在每次操作后自动保存在本机，收起、切换游戏及重启后可继续。经典精选的保存内容见下表。
- 原有三款游戏的玩家昵称最多 24 个字符，修改后点击“新一局”切换。本局仍归创建时的玩家。

## 规则与积分

### 经典精选

“小憩 → 经典精选”提供三款离线小游戏，菜单与操作提示均已汉化：

| 游戏       | 操作                                                               | 保存内容   |
| ---------- | ------------------------------------------------------------------ | ---------- |
| Q1K3       | WASD / 方向键移动，鼠标转向与射击，空格 / 右键跳跃，Q/E/滚轮换武器 | 无存档     |
| 公路赛车   | WASD / 方向键加速、刹车、转向，或按住驾驶按钮；P 暂停              | 最佳圈速   |
| 俄罗斯方块 | 左右移动、上旋转、下加速、空格落到底；P 暂停；支持按钮             | 本机最高分 |

Q1K3 来自 js13k 2021，其余两款来自 Jake Gordon 的 MIT 开源实现。俄罗斯方块为经典玩法复刻，不加载红白机模拟器或 ROM。赛车车辆、树木、路牌和背景由 Canvas 重新绘制，不打包上游受单独限制的音乐、贴图或性能统计库。作者、固定源码版本和授权见 [JS13K-GAMES.md](JS13K-GAMES.md)。

点击游戏画面获取焦点；Q1K3 会锁定鼠标，Esc 先释放，再按一次收起，释放时暂停模拟。Ctrl+Alt+G 可直接收起。关闭、切换游戏、切换文档或滚出文内视野时销毁 iframe，释放动画、音频、WebGL 和鼠标锁定。精选记录与原有昵称积分榜分开。

### 内置游戏

| 游戏     | 操作                                                           | 计分                                                                     |
| -------- | -------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 2048     | 方向键或方向按钮；相同数字合并；达到 2048 后继续               | 每次合并所得数字之和；无效移动不产生新方块                               |
| 迷你数独 | 6×6 棋盘，每行、列、2×3 宫使用 1–6；选择空格后按数字或数字按钮 | 首次正确填写 +10；完成 +100；错误不扣分，正确格不能反复刷分              |
| 轻消消   | 点击相邻两格或滑动交换，横竖三连消除；无消除的交换也保留       | 每格 +10、连消第 n 层按 n 倍；四连清行、五连全色，每四次交换赠送范围爆破 |

数独通过移除数字并验证唯一解生成题目，可不断开始新题。轻消消改为闯关旅程：第一关 30 步内得 350 分，后续逐步提高目标与难度。达标后按剩余步数获得 1–3 星，奖励为剩余步数×10＋星数×50，点击进入下一关。步数用尽可免费增加 5 步或重玩本关，没有体力、付费或广告。

每次相邻交换都会消耗一步、积累一格爆破能量；第四步自动触发以目标格为中心的 3×3 爆破。每层消除分别播放放大消散、下落补充和得分反馈，尊重系统减少动画设置。结算最多 12 层，异常随机情况下换盘，避免阻塞。新开旅程从第一关开始；下一关和重玩保留当前旅程总分，历史累计与榜单不清空。

老版本轻消消存档自动补充第一关信息，原局面、历史分数和已记账积分保持不变。关卡、步数、能量与星级一并保存；动画帧不写入存档，收起或失焦立即停止播放，下次显示已保存的结算结果。

榜单按游戏分别显示单局前 20 和玩家累计积分前 20。进行中的成绩也上榜；每次仅把新增分数计入累计，同局不会重复计分。开始新局保留累计积分和历史最好成绩。昵称只是本机档案，没有账号、联网或身份认证。

## 存储与隔离

数据使用当前 Electron 用户数据目录内的 Chromium localStorage，键为 `yarktext.arcade.v1`；仅增加一个版本化键，不读取正文或用户文件，不产生网络请求。不清理应用数据时，重启后仍保留；清理用户数据或切换应用用户目录不会带走成绩。

多窗口在 Web Locks 可用时串行更新存档，并通过 storage 事件刷新。相同游戏在各窗口继续同一局。存档解析、格式或写入失败会显示错误，不自动清空旧数据，也不会显示未成功保存的得分。

实现不依赖游戏引擎、图片素材或持续计时器。关闭浮层没有游戏更新循环。键盘监听只消费开关快捷键、浮层内的游戏按键及 Esc；游戏逻辑与 Muya、CodeMirror、文档撤销和导出完全分离。

源码入口：`packages/desktop/src/renderer/src/components/arcade/index.vue`。纯游戏规则与存档代码在 `services/arcade/`。单元测试 `arcade.spec.ts` 验证合并、唯一解、消除与计分存档；桌面同名 E2E 验证编辑隔离、收起、局面恢复和榜单。
