# 在 Markdown 中玩游戏

在正文独占一行输入 `::game 游戏名` 即可。上下可以接着写文字，不要求围栏或结束标记：

```markdown
写累了，休息一下。
::game 2048
玩完继续写。
```

| 输入            | 游戏                   |
| --------------- | ---------------------- |
| `::game 2048`   | 2048                   |
| `::game sudoku` | 迷你数独               |
| `::game match`  | 轻消消                 |
| `::game q1k3`   | Q1K3 第一人称射击      |
| `::game racer`  | 公路赛车（Racer）      |
| `::game tetris` | 俄罗斯方块（开源复刻） |

## 编辑与游玩

写下语法后，正文出现游戏卡片。语法行保持可编辑，改名后立即切换预览。点击“开始游戏”才加载游戏并接管游戏区域的操作；打开文档不会自动播放声音或锁定鼠标。

内置游戏用方向键、数字键或棋盘按钮操作。移植游戏的菜单、操作、得分和通关提示已汉化，作品原名和作者署名保留。赛车用 WASD / 方向键驾驶，P 暂停，也可按住驾驶按钮。俄罗斯方块用左右移动、上旋转、下加速、空格落到底，P 暂停，也可点击操作按钮。

点击“结束游戏”或按 Esc 收起当前文内游戏。Q1K3 的第一个 Esc 释放鼠标锁定，再按一次收起；Ctrl+Alt+G 可直接收起。滚出可见范围、切换到源码模式或切换文档会释放游戏资源，下次需主动开始。

游戏数据沿用“小憩”的本机保存规则，同一种游戏共享本机进度，不按 Markdown 文件另存。游戏分数和进度不写进正文：保存、复制、撤销与源码切换仍只处理 `::game …` 这一行。

## 普通文本与导出

- 用行内代码 `` `::game 2048` ``、代码块，或写成 `\::game 2048`，即可展示语法文字而不启动预览。
- 名称未知时显示提示卡片，保留原文以便修改。
- HTML / PDF 导出保留可读的语法文字，不嵌入应用本地路径、脚本或运行中的游戏。
- 在其他 Markdown 软件中，这一行可以作为普通文本阅读。

## 实现与验证

Muya 将指令分隔为普通段落状态；预览是非编辑附件，不参与文档状态或 Markdown 序列化。桌面组件只为附件挂载已知游戏，保留 iframe sandbox 和 CSP，不允许自定义 URL 或脚本。模式切换、删除指令及改变标识符时会卸载旧游戏。

2048 / 数独在小憩浮层与文内预览共用棋盘组件。2048 提供按数字分层的暖色方块和触屏滑动；数独保留 2×3 宫线、预置数字与填写数字的区分，并高亮选中格及所在行列和宫。

Q1K3 本地化由 `scripts/js13k-localization.mjs` 在构建时改写显示字符串；赛车和方块的中文界面及新增操作在 `scripts/game-adapters/` 适配。不修改 vendor 原件。运行 `node scripts/build-js13k.mjs` 可离线重新生成汉化资源。来源与许可见 [JS13K-GAMES.md](JS13K-GAMES.md)。

验证入口：`markdown-games.spec.ts`、`arcade-classics.spec.ts`、`arcade-js13k-3d.spec.ts`、`arcade.spec.ts`，以及 Muya 的 `gameDirective.test.ts`、CommonMark / GFM conformance 测试。
